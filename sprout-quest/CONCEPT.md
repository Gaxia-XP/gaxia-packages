# Sprout Quest — Concept · เนื้อเรื่อง · แก่นของเกม

> เกม cozy collection/exploration บนเกาะเวทมนตร์ ที่ผู้เล่นค่อยๆ ปลุกชีวิตให้เกาะกลับมาด้วยการเก็บเมล็ดเรืองแสง

---

## 1. Concept (คอนเซป)

**One-line:**
> เกม cozy collection ที่ผู้เล่น **เดินสำรวจเกาะ เก็บ Sprout เรืองแสง** เพื่อ **ฟื้นเวทมนตร์ที่กำลังจางหาย** โดยมีจุดเด่นคือ **ทุกครั้งที่เก็บ เกาะจะค่อยๆ มีชีวิตขึ้นจริงต่อหน้า**

**ขยายความ:**
Sprout Quest ไม่ใช่เกมแข่ง ไม่มีศัตรู ไม่มี fail state ผู้เล่นรับบทเป็นผู้มาเยือนคนใหม่ของเกาะ **Sprout Isle** ที่กำลังซีดเซียวลงเพราะเวทมนตร์เสื่อม หน้าที่เดียวคือออกตามหา **Sprout** — เมล็ดพันธุ์แห่งชีวิตที่ร่วงหล่นและหลับใหลอยู่ทั่วเกาะ — แล้วปลุกมันให้ตื่น ยิ่งเก็บมาก เกาะยิ่งฟื้น พื้นที่ใหม่ยิ่งเปิด

- **ประเภท:** Cozy Collection / Exploration (single-player, low-pressure)
- **กลุ่มผู้เล่น:** ทุกวัย โดยเฉพาะคนที่ชอบเกมผ่อนคลายแบบ Animal Crossing / Stardew / Adopt Me garden
- **เซสชันละ:** 5–15 นาที เล่นได้เรื่อยๆ ไม่ต้องรีบ
- **อารมณ์ที่ต้องการ:** อบอุ่น สงบ น่าพอใจ — ความรู้สึก "ฉันทำให้ที่นี่ดีขึ้น"

## 2. เนื้อเรื่อง (Story / Narrative)

### ตำนานของเกาะ

นานมาแล้ว **Sprout Isle** เคยเขียวชอุ่มและเต็มไปด้วยเวทมนตร์ หล่อเลี้ยงด้วย **ต้นไม้หัวใจ (Heart Tree)** ที่ใจกลางเกาะ ต้นไม้หัวใจจะปล่อย **Sprout** — เมล็ดเรืองแสงแห่งชีวิต — กระจายไปทั่ว ทำให้ดอกไม้บาน ต้นไม้สูง และทุกสิ่งมีชีวิตชีวา

แต่แล้ววันหนึ่ง เวทมนตร์เริ่มจางหายอย่างไม่ทราบสาเหตุ Sprout ร่วงหล่นและหลับใหล สีสันของเกาะค่อยๆ ซีดลง ถ้ำศักดิ์สิทธิ์ที่เก็บเมล็ดดั้งเดิมถูกผนึกไว้เมื่อพลังหมดลง

### ตัวละคร

- **Gardener Pip** — ผู้ดูแลเกาะคนสุดท้าย ชายชราใจดีในชุดเกษตรกร เขาแก่เกินกว่าจะเดินเก็บ Sprout ได้ทั่วเกาะแล้ว จึงรอคอยใครสักคนมาช่วย
- **ผู้เล่น** — ผู้มาเยือนคนใหม่ที่ Pip รับเป็นลูกศิษย์ และสอนวิธี "ปลุก" Sprout ให้ตื่นขึ้น

### เส้นเรื่อง (Player Journey)

1. **มาถึง Beach** — ผู้เล่นขึ้นเกาะที่ชายหาด เจอป้าย *Welcome to Sprout Isle* เกาะดูเงียบเหงาและซีด
2. **พบ Pip** — เดินไปที่กระท่อม คุยกับ Pip → Pip เล่าเรื่องเกาะที่กำลังตาย และขอให้ช่วยเก็บ Sprout *(การคุยนี้คือ gate — ต้องคุยก่อนถึงจะเก็บ Sprout ได้)*
3. **ฟื้น Meadow** — ออกเก็บ Sprout เขียวในทุ่ง แต่ละเมล็ดที่ปลุกได้ ทำให้บริเวณนั้นกลับมามีสีสัน + ได้ EXP
4. **ปลดล็อกถ้ำ (Lv.3)** — พอเวทมนตร์ในตัวผู้เล่นแรงพอ (เก็บถึงเลเวล 3) ผนึกถ้ำสลายไป → เผย **Sprout ทอง** เมล็ดดั้งเดิมที่หายากและทรงพลังที่สุด
5. **ปลุกต้นไม้หัวใจ** — เก็บ Sprout ครบ → เวทมนตร์กลับคืน ต้นไม้หัวใจตื่นอีกครั้ง เกาะเบ่งบานเต็มที่ (end state / ความสำเร็จ)

> **โทนการเล่าเรื่อง:** เล่าผ่าน dialog ของ Pip เป็นหลัก + ผ่านการเปลี่ยนแปลงของเกาะ (environmental storytelling) ไม่มี cutscene ยาวๆ ไม่มี text wall — ปล่อยให้การกระทำเล่าเรื่อง

## 3. แก่นของเกม (Core)

### Core Loop

```
คุยกับ Pip (ปลดล็อกภารกิจ)
    ↓
สำรวจหา Sprout เรืองแสง  ──►  เก็บ (แสง + เสียง + particle feedback)
    ↓                              ↓
เกาะฟื้นขึ้นเล็กน้อย  ◄──  ได้ EXP → Level up
    ↓
ปลดล็อกพื้นที่ใหม่ (เช่น ถ้ำ Lv.3) → Sprout หายากขึ้น → วนซ้ำ
```

### 4 เสาหลักของดีไซน์ (Design Pillars)

| เสาหลัก | ความหมาย | ทำไมสำคัญ |
|---------|----------|-----------|
| 🌱 **Restoration (การฟื้นฟู)** | ทุก action มีผลที่ "เห็นได้" — เกาะค่อยๆ กลับมามีชีวิต | ให้ผู้เล่นรู้สึกว่าการกระทำของตัวเองมีความหมาย |
| ☕ **Cozy (ไร้แรงกดดัน)** | ไม่มีศัตรู ไม่มี fail ไม่มีเวลานับถอยหลัง | เล่นตามจังหวะตัวเอง = ผ่อนคลายจริง |
| 🔍 **Discovery (การค้นพบ)** | Sprout ซ่อนอยู่ตามมุมต่างๆ + พื้นที่ปลดล็อกใหม่ | สร้างแรงจูงใจให้สำรวจต่อ |
| 💛 **Connection (ความผูกพัน)** | Pip เป็นตัวละครอบอุ่นที่ขับเคลื่อนเรื่องและภารกิจ | ให้เกมมี "หัวใจ" ไม่ใช่แค่เก็บของเปล่าๆ |

### บททดสอบแก่น (Core Test)

> ถ้าเอาทุกอย่างออกหมด เหลือแค่ **"เดินเจอ Sprout เรืองแสง → เก็บ"** + **"คุยกับ Pip"** — คนจะยังอยากเล่นไหม?

**ตอบ: ยัง** เพราะ feedback ตอนเก็บ (แสงวาบ + เสียง + particle + เกาะฟื้น) น่าพอใจในตัวมันเอง และความอยากรู้ว่า "Pip จะพูดอะไรต่อ / เก็บครบแล้วเกาะจะเป็นยังไง" ดึงให้เล่นต่อ → **แก่นแข็งแรงพอ**

### สิ่งที่ทำให้ Sprout Quest ต่างจากเกม collection ทั่วไป

- **เก็บแล้วโลกเปลี่ยน** — ไม่ใช่แค่ตัวเลขขึ้น แต่สภาพแวดล้อมฟื้นจริง
- **NPC เป็น gate ที่อบอุ่น** — ต้องคุยกับ Pip ก่อนเก็บ ทำให้ผู้เล่นผูกพันกับเรื่องราว ไม่ใช่ grind เปล่าๆ
- **Gating ด้วยเลเวล** — ถ้ำเปิดตอน Lv.3 สร้าง milestone ที่รู้สึกได้ + ให้รางวัล (Sprout ทอง)
