# GaxiaPackages
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0-rc.1.

## Getting Started
Install the pinned tools and open-source dependencies first:

```bash
rokit install
wally install
```

`Packages/` is generated locally and ignored by Git; `wally.lock` pins the
versions used by builds. To build the place from scratch, use:

```bash
rojo build -o "GaxiaPackages.rbxlx"
```

Next, open `GaxiaPackages.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
